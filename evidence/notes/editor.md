# 综合编辑器调试与复测记录

## 项目范围

编辑器从只读参考 DocMax 0.6.1 的源码迁移。保留 React、CodeMirror、Express 以及选区快照与结构校验、流式解析、逐词差异、全文审批、文档库、版本与审阅记录、Word 导入、论文助手、文献核实和双栏对照的实现。DocPro 增加社区修缮日示例、课程入口、独立存储命名、本地规则引擎和免安装生产构建。三次阶段作业的静态页面由同一服务的 `/course/stages/` 提供。

## 无密钥时无法审阅

初稿在无凭据的干净环境运行，正文为「居民可以进行报名。」，选择整句，要求「精简」。初版指令条根据 `!props.hasApiKey` 禁用提交。直接将同一份合法选区请求提交到本地接口，实际收到 HTTP 503 与 `missing-api-key`。修前对照存于 `evidence/initial/04/src/ui/CommandBar.tsx` 第 100 行和 `evidence/initial/04/server/editRoute.ts` 第 387 行。请求正文与原始响应分别为该目录下的 `request.json`、`before-response.txt`。

修复后，指令条在无密钥时提供「精简公文用语」与「指定替换文本」。空选区可以原样插入输入文本。客户端显式选择本地执行路径，继续复用服务端快照校验、提案构建和客户端的词级差异。相同的 JSON 正文发往 `/api/edit?engine=offline`，收到 HTTP 200 的 SSE 提案，包含原句和「居民可以报名。」。本地模式的用量为零，界面与审阅记录标为本地规则。修后原始响应在 `evidence/notes/04-after-response.txt`。实现见 `editor/src/ui/CommandBar.tsx` 第 58 行、`editor/server/editRoute.ts` 第 387 行和 `editor/server/offlineEdit.ts` 第 21 行。

## 模式提示遮住接受按钮

生成离线选区提案后，真实窗口中的「接受」位于底部提示条后面，鼠标点击等待 30 秒后超时。诊断显示 `.nokey-banner` 截获指针事件。初版底部提示使用固定定位和较高层级；进入无密钥模式后它持续显示。修前样式保存于 `evidence/initial/04/src/styles.css` 第 5132 行。

修复后，提示条作为纵向弹性布局中的普通页脚占位。窄屏显示短说明，保留配置入口。工作区和审阅栏获得剩余空间。修后样式在 `editor/src/styles.css` 第 5132 行。按原路径使用鼠标点击「接受」，原文写回，再按一次 Ctrl+Z 完整恢复。自动化的同一流程还验证了拒绝提案保留原句，以及全文两个建议分别批准和拒绝后的最终内容。

## 构建和测试记录

- 使用 Windows x64、Node.js v24.19.0、pnpm 12.3.4 与项目锁定依赖。通过前端和后端的 TypeScript 检查，Vite 构建与 esbuild 独立服务构建成功。生产服务包约 2.84 MB。
- Vitest 的 20 个测试文件共 390 项通过。输出在 `evidence/notes/editor-tests.txt`。独立服务包通过本地 Word 二进制导入，纸面排版表格和代码段均保留。
- 真正的 Chrome 连接端口 4526 的独立测试实例，6 个浏览器端到端用例全部通过。覆盖只读对照与本地文件、Word 正常导入、取消导入、图片占位、无效文件提示及离线选区/全文审阅。运行记录在 `evidence/notes/04-browser-tests.txt`。Word 表格测试同时核对转换预览的 Markdown 和编辑器内实际渲染的单元格。
- `/api/health`、`/course/` 与阶段 HTML 返回 200；`/course/editor/.env` 返回 404。服务只将课程入口与阶段目录映射到课程路径。
- 无外部模型凭据，本轮功能验证使用本地规则与本地文档处理；真实 DeepSeek 生成、联网文献检索的结果和费用均未验证。相应调用路径保留，填写有效凭据后可使用。

## 截图复现

双击根目录的 `启动编辑器.cmd`。在示例稿「社区修缮日 · 志愿者招募」的第一段按 Home 和 Shift+End 选取一行，然后按 Ctrl+K，点「精简公文用语」和「生成本地提案」。右侧显示本地识别与词级对照。要查看分块审批，可从正文上方「全文修改」入口执行相同的精简规则。


## 欢迎页与密钥确认

启动脚本现在打开 /index.html。首次进入时默认选择 DeepSeek V4.1 Flash，可先离线编辑；在线配置先由本地服务检查密钥。再次打开时显示密钥末四位，并让用户确认本次模型。通过真实编辑器和本地模拟鉴权服务检验首次保存、重启读取、确认、更换成功、凭据被拒时保留原配置，以及所选模型写入编辑器指令条。没有使用真实第三方凭据。
