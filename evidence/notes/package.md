# 提交包验收

前三个 ZIP 分别只收录纯 HTML、HTML 与 CSS、HTML 与 JavaScript 及 CSS 的定稿文件。四份报告和阶段证据收在综合包中。

四个 ZIP 均通过解压 CRC 检查。按打包清单逐项比对压缩包成员与项目文件的 SHA-256，所有成员与源文件一致。

综合包解压到项目内含中文和空格的独立临时目录。测试将 PATH 设为 Windows System32，使用随包启动脚本及 Node 运行时，并以 --no-browser 参数直接检查页面响应。生产服务返回匹配解压目录的实例标识，编辑器首页与课程入口均成功响应。新建测试文档后，从解压目录的 editor/data 读回原文。同目录重复启动返回 0 并复用服务，在另一目录启动返回 1 且给出端口占用说明。验证结束后关闭测试服务。
