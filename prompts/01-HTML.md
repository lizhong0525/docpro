# HTML 实践任务书　产品首页与使用指南

我要做一个帮助居民撰写公共文书的本地编辑器 DocPro。请先完成它的静态 index 首页，以及可以独立阅读的 about 使用指南。本次交付应在断网、双击文件和禁用脚本的条件下都可用。

1. 在页面顶部放置产品名称和分区导航，再用一个一级标题说明选区编辑的用途。正文先给一则社区公告的原稿与改稿，清楚保留时间、地点和行动要求，再用有序步骤讲解选择、审阅、应用。让用户能从首页到指南并返回原位置。
2. 使用 HTML 原生标题、段落、列表、导航地标和具名锚点。用恰当的行内语义表示新增与删除内容。主阅读区按文档阅读顺序自然铺开，让浏览器根据视口和字号自动换行。保留浏览器默认排版以单独检验 HTML 技术。
3. 产出 stages/01-html/index.html 和 about.html。保存可运行初稿，逐项检查锚点、键盘导航、小屏阅读和读者能否理解原稿与改稿。记录真实发现、修改位置与复测结果。提供初稿、终稿与对应代码，供报告原样截图。
