# CSS 实践任务书　制作双栏排版校样台

我要为 DocPro 设计一个排版校样台。请承接静态首页中「原稿与读者视角」的想法，换一篇新文稿，完成独立的 HTML 与 CSS 页面，让用户看到同一段文字经排版后如何变化。

1. 上方放文稿标题与样式选择，中间并列放置原稿和排版结果。选择两种有明确阅读用途的版式，例如适合屏读的紧凑稿和适合纸面校样的通读稿。通过原生表单控件与 CSS 状态选择器切换，保持正文内容一致。
2. 以纸白、紫墨、黄色校对标记呼应 DocMax 的稿纸意象。桌面采用约等宽双栏，内容区保留约 20–32 像素内边距；标题、行距、段间距组合体现阅读层级。窄屏改成单列，控件可换行。设计一个与校样相关的短过渡或高亮动效，同时响应减少动态效果偏好。
3. 输出 stages/02-css/index.html 和 styles.css，所有资源随阶段交付。先保留可运行初稿，再在桌面、320 像素视口与键盘输入下实际切换。记录一个经观察确认的问题、修复方法和复测结果，为报告准备页面和 CSS 对照。
