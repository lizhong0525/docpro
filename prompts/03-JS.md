# JavaScript 实践任务书　居民活动通知选区审阅

我要把 DocPro 的「只改选中的文字」做成可交互作业。请制作居民活动通知审阅练习，用户可以自由编辑原稿、选中一段、提出确定性的精简或格式建议并决定是否写回。页面明确这是本地规则练习。

1. 把可编辑稿件放在主要阅读区，将生成、接受、拒绝和一步撤销等操作放在相邻工具栏，建议区显示能读懂的修改前后差异。桌面利用并排空间，手机按原稿、操作与审阅的顺序阅读。沿用纸色与紫墨，增删同时通过文字或线型区分。
2. 用 JavaScript 保存选区起止、选中文字和文档状态。基于真实输入生成建议，保留选区外的所有字符。在等待审阅时修改原稿应使旧建议失效，接受一次可以撤销一次。对空选区、无变化、重复短语和键盘操作给出清楚反馈。
3. 提交可离线打开的 stages/03-js 页面与分离的脚本。冻结初稿，再跑空选区、重复词定位、过期建议、拒绝、接受与撤销等场景。遇到可复现问题，保存触发输入和修前源码，修后以相同路径验证，把结果交给报告编写者。
