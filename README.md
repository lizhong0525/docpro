# DocPro · 网页制作课程项目

在 Windows x64 上，将完整网站 ZIP 解压到普通可写文件夹，然后双击 **启动编辑器.cmd**。随包提供 Node.js 运行时和编译好的网页与服务。启动后首先打开欢迎页 http://127.0.0.1:4399/index.html 。首次填写 DeepSeek API Key，校验成功后保存在本机；下次启动时按末四位确认沿用或更换。写作模型默认 DeepSeek V4.1 Flash，确认后进入编辑器。未配置密钥时也可以选择离线编辑。保留启动窗口供服务运行。单独查看三次网页实践，可以直接双击本目录的 **index.html**。

## 四次作业怎么衔接

| 作业 | 页面和任务 | 这一阶段交付了什么 |
| --- | --- | --- |
| HTML | [社区文稿编辑指南](stages/01-html/index.html) | 读共享书架换书公告，沿目录阅读原句、建议和发布核对清单；首页与关于页使用纯 HTML。 |
| CSS | [河岸观察排版校样台](stages/02-css/index.html) | 一份观察手记，分别为长文阅读和展板速读排版；使用响应式网格、表单状态、动效和打印样式。 |
| JavaScript | [居民活动通知审阅](stages/03-js/index.html) | 自由编辑旧物修补活动通知、选区生成建议并接受、拒绝或撤销；通过空格与重复短语检验修改边界。 |
| 综合网站 | [本地编辑器](http://127.0.0.1:4399/editor/) | 在工作台上编辑及保存真实 Markdown 文稿，导入 Word、审阅选区或全文、管理版本并使用论文工具。 |

三次小作业用不同稿件独立演示技术。完整编辑器采用原 DocMax 的 React、CodeMirror、TypeScript 与 Express 实现。课程首页保留前序设计中的手稿和铅笔动效，将三个小作业接入同一导航。编辑器的核心及其测试来自提供的 DocMax 源码；DocPro 在独立副本中改造了品牌、入口、示例和无密钥体验。

## 体验选区审阅

1. 打开完整编辑器，在示例稿或新稿里写下「请提前进行报名。」并选中「进行报名」。
2. 按 Ctrl+K 打开指令条，选择「精简公文用语」或输入精简要求，再生成建议。审阅增删文字，接受后可以用 Ctrl+Z 撤销。
3. 在文档库新建文档并保存。用顶栏的历史、全文审阅、对照、导入 Word 和论文面板继续操作。
4. 无密钥时按页面所示使用本地演示规则。接入真实 DeepSeek 后可使用自由指令生成等模型功能，模型相关请求会传给配置的服务。文档库数据保存在解压目录的 `editor/data/` 中。

## 报告、提示词与调试证据

- `prompts/` 保存发给实现代理的四阶段任务书，分别写明内容、页面结构、技术选择和检验方法。
- `reports/` 保存四份可编辑的 Word 实践报告和相应 PDF。个人信息留空，文件名中的「学号_姓名」留待提交人替换。
- `evidence/initial/` 保存三个小作业的初稿，以及最终编辑器迁移缺陷的修前源码与响应。 `evidence/shots/` 保存独立浏览器窗口截图。报告编排所使用的源码阅读页按原文件及行号展示。
- `evidence/notes/` 保存缺陷触发条件与复测结果。报告动手验证记录描述本次真实开发操作，反思围绕相应案例展开。
- `提交包/` 中每次作业各有一份可单独提交的 ZIP。

## 源码与运行环境

Windows x64 免安装启动使用 `runtime/node.exe` 和 `editor/runtime/server.mjs`。其他平台安装 Node.js 22 或更新版本后，可以在本目录执行 `node editor/runtime/server.mjs --prod`。如要继续开发，在 `editor/` 安装锁定依赖，执行 `pnpm typecheck`、`pnpm test` 和 `pnpm build`。小作业可分别直接修改 HTML、CSS 或 JavaScript 后在浏览器刷新。
