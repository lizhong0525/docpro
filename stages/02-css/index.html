# 河岸上的四十分钟

雨停后，沿河步道的低洼处留下几块浅水面。先到的是两只麻雀，它们贴着石阶跳过去，停在草根边啄食。

## 观察方法

每隔十分钟记一次鸟的数量和落点。其余时间站在原处，给它们留出活动空间。
